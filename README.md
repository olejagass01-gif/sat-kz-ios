# SAT KZ

Мобильное приложение объявлений для Казахстана.

## Технологии
- Expo
- React Native
- TypeScript

## Запуск
`npm install`
`npx expo start`

## Первый этап
- Главный экран
- Поиск объявлений
- Категории
- Нижняя навигация

Пока используются демонстрационные объявления. Авторизация по SMS, публикация объявлений, избранное и чат будут подключены на следующих этапах.
